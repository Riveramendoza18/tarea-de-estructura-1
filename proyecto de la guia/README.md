# Trabajo Práctico Experimental 1 · Estructura de Datos

Sistema académico en Python con arquitectura MVC, CRUD, colecciones y JSON.

## Contenido

| Carpeta / archivo | Qué es |
|---|---|
| `proyecto_estudiantes/` | **La tarea (sección 14).** Sistema de estudiantes con notas, promedios y materias. |
| `proyecto_clientes/` | El sistema de clientes de la guía, con el ejercicio 6 (clientes por ciudad) como opción 8. |
| `practica.py` | Ejercicios 1 a 5 de la sección 13. |

## Cómo ejecutar

Requiere Python 3.8 o superior. No necesita instalar librerías.

```
cd proyecto_estudiantes
python main.py
```

En Mac/Linux usar `python3 main.py`. El archivo `data/estudiantes.json` trae dos estudiantes de ejemplo;
si se borra, el programa lo vuelve a crear vacío.
